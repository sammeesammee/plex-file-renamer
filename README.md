## ABOUT THE PROJECT

I wanted my media folder organized for Plex, but manual renaming was painful. Instead of learning Python like a sensible human being, I decided to prompt Gemini continuously until a matrix-themed desktop app appeared on my screen.

To my complete surprise, it actually works. It cleans messy video titles, organizes TV shows into neat folder structures, and gives off serious hacker vibes while doing so.

## FLEXED FEATURES

Despite being built on pure vibes and trial-and-error, the tool turned out surprisingly capable:

- **Matrix Rain UI Canvas:** Features a digital rain animation in the background because if an app isn't glowing green on a pitch-black background, is it even a real utility?
- **Smart Filename Extraction:** Automatically parses messy filenames containing tags like `1080p`, `x264`, `WEBRIP`, language tags (`ITA-ENG`, `SUB-ITA`), season/episode patterns, and cleans them up.
- **Plex-Compliant Formatting:** Converts chaos into structured Plex-friendly standards (e.g., `Show_Name_S01E02_Episode_Title_ITA_1080p.mkv`).
- **Multi-Season Splitter:** Detects if a directory contains multiple seasons and asks if you want to automatically move them into separate `Season-01`, `Season-02` folders.
- **Terminal Progress Bar:** Displays a live ASCII loading bar right inside the console frame during bulk operations.
- **Panic Undo Button:** Made a mistake? Hit the `[ ANNULLA MODIFICHE ]` button post-renaming to revert files back to their original names (hopefully).
- **Auto-Detection:** Automatically pre-fills series name, season number, resolution, and audio tags based on the first video file found in the chosen directory.

## HOW TO RUN IT

### Option A: The Executable (No Python Required)

If you don't have Python installed or don't want to deal with terminals, I compiled an executable for you:

1. Go to the `dist/` folder in this repository.
2. Run the executable file found inside (`app_gui.exe`).
3. Pray that Windows Defender doesn't panic.

```text
/
```

## HOW TO USE IT

1. Click `[ BROWSE ]` and select the folder containing your media files.
2. The app will attempt to guess the show title, season, language, and quality.
3. Toggle on/off whichever tags you want included in the final file name.
4. Click `[ ANALIZZA ANTEPRIMA ]` to preview changes in the system log without modifying anything.
5. If you're feeling brave, click `[ >>> ESEGUI RINOMINA PLEX <<< ]`.
6. Watch the green progress bar move.
7. If something breaks, please don't open a technical issue expecting me to debug AST syntax trees—I will just paste your issue back into Gemini and hope for the best.
